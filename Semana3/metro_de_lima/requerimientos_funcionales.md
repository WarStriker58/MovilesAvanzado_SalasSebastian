# Metro de Lima - Programa Terminal

## Requerimientos Funcionales

* **RF01.** El sistema deberá mostrar un menú principal con las opciones disponibles.
* **RF02.** El sistema deberá permitir consultar las estaciones pertenecientes a una línea seleccionada.
* **RF03.** El sistema deberá permitir consultar información de una estación ingresada por el usuario.
* **RF04.** El sistema deberá identificar las líneas a las que pertenece una estación.
* **RF05.** El sistema deberá identificar las estaciones que permiten realizar conexiones entre líneas.
* **RF06.** El sistema deberá permitir buscar estaciones mediante coincidencias parciales de texto.
* **RF07.** El sistema deberá mostrar la cantidad de estaciones pertenecientes a una línea.
* **RF08.** El sistema deberá mostrar las líneas disponibles en el sistema.
* **RF09.** El sistema deberá informar al usuario cuando la línea o estación ingresada no se encuentre registrada.
* **RF10.** El sistema deberá permitir al usuario finalizar la ejecución del sistema.
